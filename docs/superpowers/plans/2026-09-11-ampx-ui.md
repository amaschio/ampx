## Global constraints

- “The primary interface uses **AppKit and Core Graphics**, with custom controls and chrome.” Preserve the spec's exclusions of SwiftUI views, native controls/scrollbars, and SF Symbols from the primary interface.
- “Modules fill a **490 pt-wide** window at scale 1.0.” Normal UI scale remains `clamp(width / 490, 0.85, 1.35)`. Exclude the PNG's outer canvas padding.
- Preserve audio, DSP, playlist persistence, ENTHEA internals, module ordering, collapse/detach/re-dock, keyboard routing, accessibility, and effective visibility. Correct regressions exposed by drawing changes without redesigning those systems.
- Do not restore Classic, repeat migration/cutover, or revive `AmpXNewUI`. Use the completed implementation as the code baseline.
- PNG measurements override old inferred rectangles. Button classes are starting values. Distinguish visible track, thumb, travel, and hit bounds.
- No invented “canonical Winamp” overrides, standardized transport widths, or self-approved appearance deviations. Additional deviations require reference/result crops, rationale, and user approval.
- Work only on this plan's files; preserve unrelated edits. Run Python through `uv` from `scripts/`. Use Xcode tests, not `swift test`.
